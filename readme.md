## 🧰 **How QR Code Generator Works**

- The tool uses **QRCode.js**, a lightweight JavaScript library, to generate dynamic **QR codes** directly in your browser.  
- Once the **QR code** is generated, you can instantly view and download it in high-quality PNG format.  
- 🧑‍💻 **Client-Side Processing**: All QR code generation happens on the client side, ensuring privacy and speed, with no data sent to external servers.
